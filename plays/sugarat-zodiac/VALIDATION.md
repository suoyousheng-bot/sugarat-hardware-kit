# Zodiac Ring validation

Recorded results for the community release. They describe the recorded build and devices only; a rebuilt or modified image needs its own verification.

## Community release notes

Built with ESP-IDF 5.5.4. The dial, reveal, sign picker, language switch and save flow were replayed frame by frame on a computer with the same rendering code; scores match the design preview for all 12 signs. This version has not yet been checked on a badge, and frame rate on hardware is not yet measured.
