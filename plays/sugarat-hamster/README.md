# Sugarat 转转仓鼠

适用于 Sugarat ESP32-S3 圆屏徽章，以 360×360 原生分辨率显示。徽章就是笼子：小窝、跑轮支架等场景按原画 1:1 绘制，不做重采样。

仓鼠始终待在跑轮的重力最低点。转动徽章时，轮轴摩擦带动跑轮跟着笼子转，仓鼠要跑步才能留在底部；仓鼠的腿按原画的 2 像素网格绘制：奶油色毛腿加粉色脚掌，带像素描边，远侧两条腿颜色更暗；跑步时后腿一起蹬、前腿一起够，身体随步伐起伏和俯仰。跑步方向反转持续约 0.08 秒后，仓鼠会跳起转身：起跳时抬头，身体最多收窄到一半宽，在最高点翻向另一侧，同时眨一下眼，全程约 0.32 秒。停手后跑轮靠惯性滑行一会儿。仓鼠闲下来会眨眼、呼吸，偶尔自己跑一段。

仓鼠相对跑轮的最高速度约 340°/秒。跑轮跟随转动有约 0.22 秒的滞后，所以短促的快拧不会把仓鼠甩起来。持续快转时，仓鼠会被带上轮壁、失去平衡，团成球在轮里翻滚；转得够快会整圈绕着翻。停下后它会晕一会儿，转过整圈时显示「Slow down, I'm dizzy!」。开机后显示操作提示，转动约 0.6 秒或 6 秒后自动隐藏。

画面角度由屏幕法线方向的角速度推算，设备直立或倾斜且加速度可信时用重力缓慢校正。设备平放时没有重力参考，持续转动会累积误差。跑轮旋转通过预计算映射表实现，映射的旋转中心从轮毂逐渐过渡到轮圈中心，因此原画中略微偏心的轮毂和轮圈都保持不动。每帧只重绘仓鼠、跑轮和提示气泡所在的区域。

使用 ESP-IDF 5.5.4 编译。修改源画稿后运行 `python3 artwork/build_assets.py` 生成嵌入素材。
构建输出为 `build/sugarat_hamster.bin`。写入前核对设备分区表和启动选择，只写选中的兼容应用槽。
测试设备使用 `ota_0`。部署到其他设备前须核对其启动槽和实际分区，避免写入启动器或其他应用。

USB 串口发送 `s` 抓取帧缓冲截图。`~` 运行六秒模拟测试：依次施加顺转、逆转、快转和静止，期望模式日志依次出现 `tumble`、`dizzy`。`j`/`k`/`m` 分别保持模拟 150°/秒顺转、150°/秒逆转、720°/秒快转，`n` 结束模拟、回到陀螺仪输入。`t` 把转身姿态定格在 30% 处，再按一次往后推进 20%，按 `n` 解除。模拟只改输入，不带动设备实体旋转；仓鼠是否始终停在重力最低点，需要拿着实物转动来验证。

本次上板模拟测试 6 秒绘制 236 帧，单次绘制平均约 13.6 ms，最大帧间隔约 31 ms，模式依次为 tumble、dizzy。

音效使用四段内置 16 kHz 单声道素材。主动转动跑轮时按步伐播放木质脚步，反转播放起跳与落地，失衡和整圈翻滚后的眩晕提示各触发一次。音量使用控制中心设置，播放由独立音频任务处理。

工程包含发布版的字泡位图。重新生成画面时，可通过 `HAMSTER_BUBBLE_FONT` 选择英文字体；发布版用 Arial Bold。
